# Alabama & Southeast Environmental Records Watch

Independent public-interest investigation of environmental monitoring, historical contamination, cleanup progress and exposure pathways in Alabama and the Southeast. Established November 25, 2026. This repository is separate from the national Hazardous Stockpile Records Watch project.

## Scope
1. Chelsea and Shelby County
2. Greater Birmingham
3. Central Alabama
4. Alabama military environmental records
5. Alabama statewide
6. Southeastern sites with demonstrable Alabama relevance

## Repository contents
- `index.html`: static public website, searchable investigation inventory and records tracker.
- `sites.csv`: 15 starter investigation entries with official source URLs.
- `records-requests.csv`: 10 proposed requests, none submitted.
- `METHODOLOGY.md`: evidence, cost-control and publication standards.
- `CHANGELOG.md`: version history.

## Publication
Use Settings → Pages → Deploy from a branch → main → /(root). No build tooling is required. For updates, revise the CSVs and corresponding HTML tables and counts together; they are not automatically synchronized. The website filters only the displayed HTML, and does not store user inputs or send them to a server.

## Status and corrections
The launch inventory is a selected subset of the preliminary investigation, not a comprehensive assessment. Stable IDs are retained, and gaps are intentional. Listed locations are not declarations of danger. Open a repository issue for corrections or public source suggestions; do not submit confidential information. Rights in third-party records remain with their respective holders.
